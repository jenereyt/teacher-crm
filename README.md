# Мои ученики: CRM для частного преподавателя

Сайт для учёта учеников, расписания, посещаемости, домашних заданий и оплат. Работает в браузере на компьютере и телефоне, сервер не нужен.

## Что умеет

- **Ученики**: контакты, родители, уровень, статус (занимается / пробный / пауза / ушёл), заметки, баланс.
- **Группы**: состав, цена, цвет.
- **Расписание**: день, неделя и месяц; регулярные занятия (например, Пн и Чт в 16:00) появляются автоматически.
- **Занятие**: посещаемость (был / опоздал / не был / уважительная причина), тема, ДЗ, оценки, отметка «ДЗ сделано».
- **Оплаты**: разовые оплаты и абонементы на N занятий, баланс и долги считаются автоматически.
- **Главная**: занятия на сегодня, неотмеченные занятия, должники, доход за месяц, дни рождения.
- **Сообщения родителям** по шаблонам: WhatsApp, Telegram, SMS или копирование текста.
- **Резервная копия**: JSON (полная) и CSV для Excel; загрузка учеников из CSV.
- Светлая и тёмная тема, установка на главный экран телефона.

## Где хранятся данные

В браузере (localStorage) того устройства, на котором открыт сайт. В репозиторий данные не попадают.
Чтобы данные были одинаковыми на ноутбуке и телефоне, включите синхронизацию через **закрытый** репозиторий GitHub: «Настройки → Синхронизация» (там пошаговая инструкция). Нужен fine-grained token с доступом только к репозиторию данных и правом Contents: Read and write. Данные лежат файлом `data.json`, GitHub хранит историю его изменений.

## Разработка

```bash
npm install
npm run dev     # локальный сервер
npm run build   # сборка в папку dist
```

Каждый push в ветку `main` автоматически публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
